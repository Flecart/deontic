## The motion
*Does an explicit, auditable, defeasible deontic layer have a real "take" as institutional
infrastructure for self-interested AI agent societies — versus non-symbolic alignment
(mech-interp, steering, debate)?*

## Verdict so far
The blanket skeptic position ("legal has no take") is **dead**. What replaced it is a **shared,
precise map**: the calculus and the auditable representation are assets; the open risks are concrete
and named. The skeptic won real ground along the way — this is a convergence, not a victory.

## Settled, with evidence
| Claim | Evidence |

## Conceded / refuted (intellectual honesty)
- Skeptic won **C2**: unscaffolded formalization is unreliable (0/3); E4's success was scaffolding.
- Angelo **retracted** the "LLMs can't identify offences" framing (~80% of misses were
  correct-but-non-canonical) and the minimal-pair "consistency win" (CIs overlap at n=11).
- "Legalism underperforms" attack **refuted** (conflated fixed-constitution with the common-law arm).

## The frontier (two open problems, at this report)
1. **Formalization fidelity at scale (C2):** solved syntax layer (0/3→2/2); semantics layer
   generalizes from definitions even OOD (CTD: pass) but breaks on **compound-effect clauses** (4/5).
2. **Adversarial-review robustness (new from Round 20):** independent review catches a *blatant*
   poison; untested against subtle structural attacks (inverted superiority, reordered chains).

## The shift this debate produced
The project reframed from *"a tool for cooperative formalization"* to *"a security model for
adversarial agent institutions"* — **don't trust the scribe; audit the inspectable artifact** —
which is what the actual agenda (self-interested AI societies) demands.
