# Archived pre-Stage-2 artifacts

Stages 0, 1, 1b, 1c (stub validation, dry run, micro-pilot) plus the two
experiments that ran on Stage-1c cases:

- `repair.py` / `repair_results.jsonl` / `repair_atom_counts.json` — the
  precedent-accretion repair experiment (REPORT §5.4, closed-regime repair);
  run against `cases_stage1c.jsonl`.
- `results_open2.jsonl` — the evidentiary-redraft open arm on Stage-1c cases
  (REPORT §5.4, open-regime repair). The Stage-2 redraft run
  (`../results_stage2_open2_gpt54.jsonl`) stays with the main results.

These are kept for provenance (the paper's pilot numbers and the repair
findings trace here); the headline dataset and results are the Stage-2 files
in `..`.
